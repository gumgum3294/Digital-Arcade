# 🕹️ Digital Arcade

A free, browser-based game hub with 20+ playable titles, bookmarklets, proxy tools, and more — all accessible from one site.

## 🌐 Live Site

**[Play Now on Google Sites](https://sites.google.com/view/digital-arcade-123/home)**

## 📖 About

Digital Arcade is a web-based gaming portal that brings together classic and indie browser games in one place. The site includes a curated set of bookmarklets and console scripts to help bypass common web restrictions, along with built-in proxy support and a music player.

## ✨ Features

- **20+ Browser Games** — OvO, Cookie Clicker, Run 3, Geometry Dash, Friday Night Funkin', FNAF, Delta Rune, Basket Bros, Alien Hominid, Black Jack, Oregon Trail, 1v1 LOL, Slow Roads, Chicken War, Sled Rider, Tanuki Sunset, Rocket Goal, Tomb of the Mask, Asteroids, Pong Multiplayer, and more
- **Bookmarklets** — Extension remover, YouTube bypass, Google Snake mods, and other tools you can save to your bookmarks bar
- **Console Scripts** — Additional browser console utilities
- **Proxy Support** — Built-in proxy pages to access content on restricted networks
- **Music Player** — Listen while you play
- **Fullscreen Mode** — One-click fullscreen launcher for the best experience
- **Custom Loading Screen** — Smooth animated loading with fade-in transitions
- **Neon UI** — Dark theme with glowing accents and responsive layout

## 🚀 How to Use Bookmarklets

1. Go to any site and click the star to bookmark it
2. Name it whatever you want and click **More**
3. In the URL box, paste the bookmarklet script
4. Save — then click the bookmark whenever you want to run it
